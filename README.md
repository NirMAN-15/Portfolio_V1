# W. Nirman Achintha — Portfolio

Personal portfolio website showcasing my projects, technical skills, and contact information.

Built with React, Vite, and Vanilla CSS.

## Live Site

[https://nirman-15.github.io/Portfolio_V1/](https://nirman-15.github.io/Portfolio_V1/)

## Tech Stack

- **Frontend:** React 19, React Router, Lucide Icons
- **Styling:** Vanilla CSS with custom design tokens
- **Build Tool:** Vite
- **Deployment:** GitHub Pages via GitHub Actions

## Running Locally

```bash
npm install
npm run dev
```

## Building for Production

```bash
npm run build
npm run preview
```

## Deployment

This project auto-deploys to GitHub Pages on every push to `main` using the workflow in `.github/workflows/deploy.yml`.
